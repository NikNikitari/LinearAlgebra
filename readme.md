# Linear Algebra

Простой проект на C++ для работы с векторами и матрицами размерностей 2D, 3D и 4D.

## Что реализовано

- Классы `Vector2D`, `Vector3D`, `Vector4D`
  - конструкторы по умолчанию
  - конструкторы из массива и initializer_list
  - оператор доступа по индексу `[]`
  - сравнение `==` и `!=`
  - сложение `+`
  - скалярное произведение `*`

- Классы `Matrix2D`, `Matrix3D`, `Matrix4D`
  - конструкторы по умолчанию
  - конструкторы из массива и initializer_list
  - оператор доступа по индексу `[]`
  - оператор доступа по координатам `(x, y)`
  - сравнение `==` и `!=`
  - сложение `+`
  - умножение матрицы на матрицу `*`
  - умножение матрицы на вектор `*`
  - вычисление детерминанта `det()`

## Структура проекта

- `CMakeLists.txt` — конфигурация сборки
- `include/` — заголовочные файлы для 2D, 3D и 4D классов
- `src/` — реализации классов
- `test/` — набор модульных тестов на основе Google Test

## Сборка

В папке проекта выполните:

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## Тесты

Для запуска тестов выполните в каталоге сборки:

```bash
ctest --output-on-failure
```

Или напрямую:

```bash
./tests/LinearAlgebraTests
```

## Примечания

Проект использует `FetchContent` для автоматической загрузки Google Test при сборке.
